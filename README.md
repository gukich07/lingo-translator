# LINGO — русско-английский переводчик

Адаптивный переводчик RU ↔ EN для компьютера и телефона. Это PWA-приложение с тёмной/светлой темой, историей и инструментами ввода.

## Возможности

- Перевод русского и английского текста с автоматическим выбором направления по алфавиту исходного текста.
- Основной движок — Google Translate через используемый веб-интерфейсный endpoint без API-ключа. Он обычно лучше подходит для связного текста, чем перевод через очень короткие фрагменты.
- Резервный перевод MyMemory для коротких текстов, если основной сервис временно недоступен.
- Обработка текстов до 50 000 символов с разбиением по границам предложений/слов; пробелы и разделители между фрагментами сохраняются.
- Автоматический предварительный перевод во время ввода и финальный перевод после небольшой паузы.
- Копирование и озвучивание перевода.
- Голосовой ввод там, где браузер поддерживает Web Speech API.
- Извлечение русского и английского текста с фотографии через Tesseract.js; при первом использовании библиотека загружается из интернета.
- История до 100 переводов на устройстве, очистка истории и восстановление прошлых переводов.
- Автоматическая, светлая и тёмная темы.
- PWA-кэш оболочки: при отсутствии сети доступны интерфейс и локальная история.
- Адаптация под мобильные экраны и симметричное расположение кодов языков.

## Важно о качестве и доступности перевода

Для запуска не нужен секретный ключ переводческого сервиса.

Основной движок обращается к неофициальному веб-endpoint перевода Google, который не является документированным API для разработчиков. Это позволяет запустить прототип без регистрации и API-ключа, но стабильность не гарантируется: endpoint может ограничивать частоту запросов, блокировать часть серверных подключений или менять формат ответа. Если это произойдёт, LINGO попробует MyMemory для короткого текста; длинный текст может потребовать повторной попытки. Качество машинного перевода зависит от контекста и не гарантируется на 100%.

Текст отправляется во внешний сервис перевода. Не вставляйте пароли, личные документы или другую конфиденциальную информацию. Для надёжного публичного продукта в дальнейшем лучше подключить официально поддерживаемый переводческий API и соблюдать его условия и лимиты.

Лимит в 50 000 символов — максимальный размер поля ввода, а не гарантия, что внешний сервис всегда примет текст такого размера. Большой текст разбивается на несколько запросов; скорость зависит от сервиса и сети.

## Запуск локально

PWA и service worker работают через `localhost` или HTTPS, а не при открытии `index.html` напрямую.

### Python

1. Распакуйте архив.
2. Откройте терминал в папке `lingo-translator`.
3. Выполните:

   ```bash
   python -m http.server 8000
   ```

4. Откройте `http://localhost:8000`.

### VS Code

Откройте папку проекта в VS Code и запустите её через расширение Live Server.

## Публикация через GitHub и Vercel

1. Создайте репозиторий GitHub.
2. Загрузите содержимое папки `lingo-translator` в корень репозитория. В корне сразу должны лежать `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg` и папка `api`.
3. В Vercel импортируйте репозиторий. Для обычного статического проекта выберите Framework Preset `Other` и оставьте build-команду пустой.
4. Выполните Deploy. После новых коммитов Vercel автоматически пересоберёт сайт.

Серверная функция `api/translate.js` используется на Vercel. На статическом хостинге без serverless-функций интерфейс попробует обратиться к переводческому endpoint напрямую из браузера; доступность этого пути зависит от CORS и ограничений сервиса.

## Структура

- `index.html` — интерфейс
- `styles.css` — оформление и адаптивность
- `app.js` — логика интерфейса, ввод, история и перевод
- `api/translate.js` — серверный перевод для Vercel, с резервом для короткого текста
- `sw.js` — офлайн-кэш оболочки
- `manifest.webmanifest` — установка приложения как PWA
- `icon.svg` — иконка приложения
