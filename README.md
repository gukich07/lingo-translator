# Lingo — русско-английский переводчик

Адаптивное PWA-приложение для браузера на компьютере и телефоне. Светлая/тёмная тема автоматически следует системным настройкам.

## Что работает

- Перевод RU ↔ EN через реальный API MyMemory.
- Автоматическое определение направления по буквам текста.
- Копирование результата.
- История последних 100 переводов в `localStorage` браузера.
- Озвучивание через Web Speech API (голоса установлены в браузере/ОС).
- Голосовой ввод через Web Speech API, если его поддерживает браузер.
- PWA-кэш интерфейса: приложение открывается повторно без сети, история доступна офлайн.
- Адаптивная вёрстка, клавиатурное сочетание Ctrl/⌘ + Enter, обработка сетевых ошибок и ограничений API.

## Важное ограничение офлайн-перевода

Сам перевод выполняется внешним сервисом и требует интернет-соединения. Без сети приложение всё равно запускается, а сохранённая история остаётся доступна, но новый текст перевести нельзя. Это намеренно: приложение не подменяет реальный перевод фиктивным результатом. Для настоящего офлайн-перевода нужен встроенный языковой движок/модель (что значительно увеличит размер приложения) либо собственный локальный сервер.

Голосовой ввод обычно использует возможности браузера и может требовать сеть/разрешение микрофона. Доступность зависит от браузера и ОС.

## Запуск локально

Service Worker и PWA работают через `localhost` или HTTPS, не при открытии `index.html` напрямую.

### Вариант 1: Python

1. Распакуйте архив.
2. Откройте терминал в папке `lingo-translator`.
3. Запустите:

   ```bash
   python -m http.server 8000
   ```

4. Откройте `http://localhost:8000`.

На телефоне для тестирования в той же Wi-Fi сети можно открыть `http://IP-АДРЕС-КОМПЬЮТЕРА:8000`, но сервис-воркер на телефоне обычно требует HTTPS; для установки PWA разверните приложение на HTTPS-хостинге.

### Вариант 2: VS Code

Установите расширение Live Server, откройте папку проекта и выберите **Open with Live Server**.

## Публикация

Можно развернуть статические файлы на любом HTTPS-хостинге, например GitHub Pages, Netlify или Cloudflare Pages. Серверная часть не нужна для текущего публичного API.

## API и приватность

- Endpoint: `https://api.mymemory.translated.net/get`
- Для перевода текст отправляется стороннему сервису. Не вводите пароли, персональные или конфиденциальные данные.
- У публичного сервиса могут быть лимиты, задержки или временные сбои. В приложении отображаются ошибки вместо выдуманного перевода.
- Для продакшена с большим количеством пользователей рекомендуется собственный backend и проверенный тариф/поставщик API. Не храните секретные API-ключи в клиентском JavaScript.

## Файлы

- `index.html` — интерфейс
- `styles.css` — оформление и адаптивность
- `app.js` — перевод, история, озвучивание, микрофон
- `sw.js` — офлайн-кэш приложения
- `manifest.webmanifest` — установка как PWA
- `icon.svg` — иконка


## Обновления интерфейса
- Нажатие на логотип возвращает фокус к полю ввода, а не открывает папку/не уводит со страницы.
- Предварительный перевод обновляется при завершении каждого слова (пробел/пунктуация); после паузы полный текст переводится повторно и сохраняется в истории. Перевод API всё равно зависит от скорости сети и сервиса, поэтому это не посимвольный локальный перевод.
- Кнопка «Фото» распознаёт русский и английский текст с изображения через Tesseract.js (при первом использовании нужна загрузка библиотеки из интернета), затем автоматически переводит распознанный текст.
- Сам перевод по-прежнему требует интернет-соединения и доступности MyMemory API.


## Публикация в интернете через GitHub + Vercel

### 1. Создать репозиторий GitHub
1. Зарегистрируйтесь/войдите на GitHub и откройте https://github.com/new.
2. Назовите репозиторий, например `lingo-translator`, выберите **Public** (или Private, если хотите закрытый исходный код) и нажмите **Create repository**.
3. Распакуйте ZIP на ПК. Откройте вложенную папку `lingo-translator` — в ней должны сразу лежать `index.html`, `styles.css`, `app.js`, `sw.js`, `manifest.webmanifest`, `icon.svg`.
4. В новом репозитории нажмите **Add file → Upload files** и перетащите эти файлы (не ZIP и не внешнюю папку целиком) в окно браузера. Нажмите **Commit changes**.

### 2. Развернуть на Vercel
1. Откройте https://vercel.com/ и выберите вход через GitHub. Подтвердите доступ к созданному репозиторию.
2. В панели Vercel нажмите **Add New… → Project**, найдите `lingo-translator` и нажмите **Import**.
3. Для этого статического проекта выберите Framework Preset **Other**. Build Command и Output Directory оставьте пустыми/по умолчанию; корень проекта должен содержать `index.html`.
4. Нажмите **Deploy**. После завершения Vercel выдаст HTTPS-адрес вида `https://lingo-translator-....vercel.app`. Откройте его и проверьте перевод, фото и переключение темы.
5. На телефоне откройте эту HTTPS-ссылку в Chrome → меню ⋮ → **Установить приложение** или **Добавить на главный экран**.

### 3. Как публиковать изменения
После изменения файлов на ПК загрузите их в тот же GitHub-репозиторий через **Add file → Upload files** и сделайте **Commit changes**. Vercel автоматически соберёт и опубликует новую версию. Если телефон показывает старую версию, обновите страницу; кэш приложения уже использует новую версию оболочки.

### Важные ограничения
- Фото: на смартфоне атрибут камеры просит открыть заднюю камеру, но окончательное поведение зависит от браузера/ОС; если камера не запускается сразу, в системном выборе выберите «Камера».
- MyMemory — публичный сторонний API с лимитами. Для публичного сайта с большим числом пользователей следует проверить условия сервиса и рассмотреть собственный backend/API-провайдера.
