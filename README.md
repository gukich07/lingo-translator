# Lingo — русско-английский переводчик

Адаптивное PWA-приложение для браузера на компьютере и телефоне. Светлая/тёмная тема автоматически следует системным настройкам.

## Что работает

- Перевод RU ↔ EN через реальный API MyMemory.
- Автоматическое определение направления по буквам текста.
- Копирование результата.
- История последних 100 переводов в `localStorage` браузера.
- Озвучивание через Web Speech API (голоса установлены в браузере/ОС).
- Голосовой ввод через Web Speech API, если его поддерживает браузер.
- PWA-кэш интерфейса: приложение открывается повторно без сети, история доступна офлайн.
- Адаптивная вёрстка, клавиатурное сочетание Ctrl/⌘ + Enter, обработка сетевых ошибок и ограничений API.

## Важное ограничение офлайн-перевода

Сам перевод выполняется внешним сервисом и требует интернет-соединения. Без сети приложение всё равно запускается, а сохранённая история остаётся доступна, но новый текст перевести нельзя. Это намеренно: приложение не подменяет реальный перевод фиктивным результатом. Для настоящего офлайн-перевода нужен встроенный языковой движок/модель (что значительно увеличит размер приложения) либо собственный локальный сервер.

Голосовой ввод обычно использует возможности браузера и может требовать сеть/разрешение микрофона. Доступность зависит от браузера и ОС.

## Запуск локально

Service Worker и PWA работают через `localhost` или HTTPS, не при открытии `index.html` напрямую.

### Вариант 1: Python

1. Распакуйте архив.
2. Откройте терминал в папке `lingo-translator`.
3. Запустите:

   ```bash
   python -m http.server 8000
   ```

4. Откройте `http://localhost:8000`.

На телефоне для тестирования в той же Wi-Fi сети можно открыть `http://IP-АДРЕС-КОМПЬЮТЕРА:8000`, но сервис-воркер на телефоне обычно требует HTTPS; для установки PWA разверните приложение на HTTPS-хостинге.

### Вариант 2: VS Code

Установите расширение Live Server, откройте папку проекта и выберите **Open with Live Server**.

## Публикация

Можно развернуть статические файлы на любом HTTPS-хостинге, например GitHub Pages, Netlify или Cloudflare Pages. Серверная часть не нужна для текущего публичного API.

## API и приватность

- Endpoint: `https://api.mymemory.translated.net/get`
- Для перевода текст отправляется стороннему сервису. Не вводите пароли, персональные или конфиденциальные данные.
- У публичного сервиса могут быть лимиты, задержки или временные сбои. В приложении отображаются ошибки вместо выдуманного перевода.
- Для продакшена с большим количеством пользователей рекомендуется собственный backend и проверенный тариф/поставщик API. Не храните секретные API-ключи в клиентском JavaScript.
